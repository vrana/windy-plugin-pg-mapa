# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

An external plugin for [Windy.com](https://www.windy.com) titled **Paragliding Mapa** (route
`/pgmapa`). It overlays paragliding takeoffs on the Windy map and colors each by whether the
forecast wind is usable there. Takeoff data comes from a remote API
(`https://pg.vrana.cz/xcontest/pgmapa.php`); weather comes from Windy's own store/fetch APIs.
This is essentially the Windy-embedded version of the standalone app at
`https://pg.vrana.cz/mapa/` (see the note at [src/plugin.svelte:72](src/plugin.svelte)).

## Commands

- `npm start` – rollup watch build; serves `dist/` over HTTPS on `localhost:9999` (self-signed
  cert from `dev/`). Load the running plugin from https://www.windy.com/dev.
- `npm run build` – clean production build into `dist/` (`plugin.js` and minified
  `plugin.min.js`), then copies `package.json` in.
- `npm test` (= `npm run prepublishOnly`) – runs `test/prepublish.js`. **These are not unit
  tests**: they only assert that `package.json`/`README.md` were not left at the plugin-template
  defaults. There is no unit/integration test suite.
- Publishing: trigger the **publish-plugin** GitHub Action manually
  ([.github/workflows/publish-plugin.yml](.github/workflows/publish-plugin.yml),
  `workflow_dispatch`); it builds and uploads the archive to Windy using the `WINDY_API_KEY`
  secret. Nothing publishes automatically on push.
- **Windows note:** the `build` script uses POSIX `rm`/`mkdir`/`cp` and `SERVE=false ...`
  env-var syntax, so run it through the Bash tool / a POSIX shell, not PowerShell.
- There is an `.eslintrc.json` but no lint script in `package.json`.

## Architecture

- **Almost everything lives in [src/plugin.svelte](src/plugin.svelte)** (~860 lines) – a single
  Svelte component holding all the logic. [src/pluginConfig.ts](src/pluginConfig.ts) is only
  plugin metadata (`ExternalPluginConfig`: title, icon, `routerPath`, desktop/mobile UI mode).

- **`@windy/*` imports are runtime-external.** rollup marks any `@windy/` id as external
  ([rollup.config.js:46](rollup.config.js)); Windy provides `store`, `map`, `broadcast`,
  `fetch`, `interpolator`, and `utils` at runtime. Leaflet (`L`) and Windy (`W`) are globals.
  Do not try to bundle these.

- **Lifecycle:** `onopen` → `init()` registers `broadcast.on('redrawFinished', redraw)` and
  `map.on('moveend', redraw)`, and fetches the takeoff list once. `onDestroy` removes markers
  and detaches the listeners.

- **Data model:** `sites` is keyed by a `"latitude longitude"` string; nearby takeoffs are
  merged into one entry/marker (e.g. "Raná SZ" + "Raná JV"). `markers` and `names` are parallel
  maps of Leaflet markers keyed the same way. `winds`/`forecasts`/`airDatas` are per-model
  caches. `getLatLon(str)` parses a key back into `{lat, lon}`; `getWindsKey()` builds a cache
  key from the current overlay/level/timestamp.

- **Coloring:** `getColor` + `getSpeedIndex` + `getDirIndex` implement the wind-usability color
  scheme documented in the README (green / yellow / silver / red / black / white). Marker icons
  are inline SVG data-URIs from `getIconUrl` / `getCircleSlice`; size scales with zoom and
  flight count in `newIcon`.

- **Weather:** wind comes from the live `wind` overlay interpolator when that overlay is active,
  otherwise from `windyFetch.getPointForecastData`. `windyFetch.getMeteogramForecastData`
  (airData) feeds the `computeCeiling` thermal/cloud-base calculation and the interactive
  `showSounding` SVG sounding diagram.

- **i18n:** `translate(english, czech)` selects the language from `store.get('lang')` /
  `usedLang`; only English and Czech exist. Tooltips are assembled as raw HTML strings, so run
  site/user text through `html()` (manual HTML escaping) when interpolating it.

## Conventions

- **The version lives in two files and must be bumped together:** `version` in
  [package.json](package.json) and `version` in [src/pluginConfig.ts](src/pluginConfig.ts).
- The active takeoff data source is `getApiUrl()` in [src/plugin.svelte:37](src/plugin.svelte);
  commented-out alternatives (paragliding-mapa.cz, DHV, Paragliding Earth) sit right below it.
- Indentation is tabs; several eslint rules (`indent`, `no-mixed-spaces-and-tabs`,
  `no-fallthrough`, `no-cond-assign`) are intentionally disabled.
- `dist/` holds build artifacts and is regenerated by `npm run build`.
